# 法律援助多智能体接待平台

三创赛开发原型，把群众接待、来源检索、材料整理、人员候选与人工审核连接为可追溯工作流。按用户提供的《法律援助多智能体平台开发方案 V1.0》分阶段实现，每阶段验证后独立提交并推送。

**当前仅供虚构数据演示。** 内置知识和名录都是模拟样本，不是经机构授权的业务资料。系统不自动审批法援资格、不正式指派律师、不出具个案法律意见。

## 本地运行

需要 Python 3.12、Node.js 22+ 和 npm。首次安装：

```bash
PYTHON_BIN=python3.12 ./scripts/setup.sh
cp .env.example .env
./scripts/dev.sh
```

现场触屏请打开 <http://127.0.0.1:3000> 并全屏显示。工作人员在独立浏览器打开 <http://127.0.0.1:3000/staff>，接口文档在 <http://127.0.0.1:8000/docs>。Ctrl+C 可停止两个服务。

默认开发密码为 `local-demo-change-me`，可在 `.env` 中修改 `DEMO_PASSWORD`。只用于绑定本机的演示环境，不能直接暴露到公网。账号由后端确定角色：

| 用户名 | 角色及能力 |
| --- | --- |
| `staff` | 查看咨询、人工审核建单、跟进工单 |
| `reviewer` | 维护与审核知识 |
| `admin` | 管理知识、名录并处理咨询 |
| `auditor` | 只读脱敏审计和运行指标 |

公众触屏无需登录。当前信息只保留在浏览器页面内，完成后可立即返回首页，30 秒后自动返回，使用中 3 分钟无操作自动清屏。已登记的演示记录仍保存在服务端，默认位于 `apps/api/data/`。

## 功能与边界

- 现场触屏采用法治红主题。首页提供「开始咨询」「请工作人员帮助」。常见事项可点选登记、返回修改、核对并提交，完成后凭编号去人工服务台。
- 五类智能体：调度监督、接待、知识检索、证据整理、人员匹配与工单；结构化输出、版本、工具权限和运行轨迹。
- 工作人员后台：待办、详情、候选人员、复核意见、工单处理与关闭。
- 管理与审计：知识草稿/审核/停用、模拟名录、角色控制、审计记录和费用指标。
- 语音说明为可选项。配置本地 Whisper 后，录音时显示实时中文字幕，停止后用完整录音转写并回填可编辑文字。授权 UTF-8 文本材料整理保留在后台的接待测试入口。[语音配置](docs/OPERATIONS.md#现场语音检查)
- 电话测试台：模拟转写、打断、识别失败和断线事件。**尚未接入真实号码、SIP、流式音频或真人电话转接。**
- 模型网关：支持 DeepSeek Flash 补充自由说明中的登记字段。启用后，触屏端在「语音或文字说明」中单独征求同意。纯点选及规则已提齐字段的咨询继续本地处理。已用虚构案例跑通真实 DeepSeek 接口、摘要核对与提交。配置和范围见[运维手册](docs/OPERATIONS.md#外部模型配置)。

技术栈：Next.js、React、TypeScript；FastAPI、Pydantic、SQLAlchemy。默认 SQLite；支持配置 PostgreSQL 连接，但本轮只验收 SQLite。本地单进程演示的存储和鉴权不能替代生产的机构隔离与身份系统。

## 验证与部署

```bash
./scripts/check.sh
# 保持服务运行，在另一个终端执行
apps/api/.venv/bin/python scripts/api_smoke.py --wait
# 批量评测需按操作手册提高专用测试环境限流额度
apps/api/.venv/bin/python scripts/evaluate.py
# Docker 引擎可用时
docker compose up --build
```

固定模板虚构语料的回归结果不代表独立业务准确率；50 次 HTTP 转人工状态检查不代表真实工作人员接通率。具体测试结果与未验收事项见下方文档。容器端口默认只绑定本机，Docker 配置和真实容器运行分别记录。
