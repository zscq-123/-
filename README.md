# 法律援助多智能体接待平台

依据《法律援助多智能体平台开发方案 V1.0》开发的三创赛原型，连接接待、来源检索、材料整理、人员候选与人工审核。

当前为模拟开发环境，只使用虚构咨询、流程样本及人员。不作资格审批、正式指派或个案法律意见。真实电话、机构名录、知识业务审核和受控试点需另行完成。
