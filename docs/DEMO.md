# 模拟演示脚本

演示只使用本仓库虚构数据，开始时明确告知观众“当前是软件原型与模拟流程”。录屏前准备新数据库并核对代码提交编号。不要录入身份证件、真实姓名、电话号码、真实案卷或真实人员名录。

## 场景一 触屏接待到人工工单

1. 在群众终端打开 `/`，首页显示“开始咨询”和“请工作人员帮助”。不要展示工作人员菜单或要求群众登录。
2. 点“开始咨询”，阅读用途、数据范围和人工入口的告知，确认后进入分步登记。
3. 依次选择“劳动争议”、填写“烟台市”、选择“2026-10-01”、填写诉求“了解工资记录如何整理”。页面默认不要求姓名、身份证号或电话号码。
4. 在核对页逐项检查事项、地点、时间和诉求；有误时返回对应步骤修改。查看模拟流程提示与摘要，来源标记为模拟，不能证明真实资格或办理规则。
5. 点“确认提交”，进入等待工作人员接续的完成页。演示者选择结束、返回首页，确认屏幕不再显示本次内容。
6. 用另一窗口打开 `/staff`，工作人员登录查看待办队列、摘要、候选人员和智能体运行轨迹，填写审核意见并创建工单。
7. 工单改为处理中、再关闭。解释它是人工待办记录，不是法律援助批准或正式律师指派。

在工作人员工作台可单独演示虚构 UTF-8 `.txt` 材料授权与目录整理。图片、PDF、OCR 和病毒扫描未集成，不展示为已支持。

## 场景二 人工帮助与终端清屏

首页点“请工作人员帮助”，按页面提示等待现场工作人员协助，不强迫填写事项。登记中也可退出自动流程请求人工。查看后台时，要区分仅显示现场帮助提示与已创建、进入人工队列的会话。

另建一份未提交的虚构登记，停止操作 3 分钟，检查页面是否清屏并回到首页；返回后不能看到上一位使用者的内容。再完成一次提交并点击结束返回，检查同样的清屏行为。录屏应保留实际等待过程或可核验时间标记，不能把“前端清屏”描述为“后台记录删除”。

## 场景三 电话事件与浏览器语音

在 `/staff` 的电话模拟入口依次发送模拟告知、转写、打断、断线或识别失败事件，展示状态保存及人工回退。界面必须一直保留“模拟”标识。这一演示没有真实号码、SIP 音频、运营商接入或真实转接。

触屏登记可另外选择语音录入。浏览器语音只有在浏览器支持、麦克风许可和单独语音处理同意后才测试。浏览器可能使用第三方识别服务，提前使用虚构内容；拒绝权限或不支持时回退文字。朗读可停止，不能将浏览器 TTS 当作流式电话语音验收。

## 场景四 管理和审计

在 `/staff` 使用审核人账户登记模拟知识草稿，填写来源、版本、地区、定位，审核发布后查看；停用后确认不再用于检索。管理员可以维护虚构人员资格描述、领域、地区、可用和停用状态。审计员查看脱敏事件和运行指标，但不能创建工单或修改配置。
