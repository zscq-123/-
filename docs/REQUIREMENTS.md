# 原开发方案与软件交付对应

依据用户提供的《法律援助多智能体平台开发方案》V1.0（2026-11-17），本仓库保留人工最终负责、来源可定位、最小必要数据、工具隔离和失败转人工五项约束。下列内容是实现与验收依据，完成状态见 PROGRESS 和 EVALUATION。

## 首期工作流

1. 群众阅读告知并同意，以文字、浏览器语音或电话事件模拟进入接待。
2. 分步记录事项、地点、时间、诉求、材料；任何时候可转人工。
3. 调度与监督层依据显式状态调用接待、知识、材料及人员匹配模块。
4. 知识回答保存来源、版本、定位、适用地区；未找到来源转人工。
5. 本人可修改字段、复核摘要；修改之后旧确认失效。
6. 后台工作人员检查摘要、材料、候选与风险，记录复核意见后创建工单。
7. 工单可继续处理及关闭，所有变更可追溯。

## 不可自动化的决定

法律援助资格审批、利益冲突最终核查、正式人员指派、个案法律意见及对外通知不能由智能体自行执行。人员候选仅作人工复核参考。

## 原八周任务追踪

| 原计划 | 软件交付内容 | 必须实际开展的外部工作 |
| --- | --- | --- |
| 第1周 需求边界与线路 | 架构、接口、权限和模拟渠道设计 | 机构访谈、运营商/PBX确认、范围签字 |
| 第2周 数据状态与原型 | 持久模型、状态机、种子来源、固定模拟案例、页面 | 数据与流程业务评审 |
| 第3周 核心智能体 | 接待、监督调度、带来源检索与摘要确认 | 真实业务知识审核 |
| 第4周 语音电话材料 | 浏览器语音、文本材料、电话事件模拟、回退 | 真线路双向音频、流式ASR/TTS、真实转接 |
| 第5周 人员与工单 | 硬规则筛选、人工审核、工单及审计 | 名录授权、资格和利益冲突核验 |
| 第6周 安全运维 | 角色控制、费用指标、备份、部署配置 | TLS与机构环境、存储及运维评审 |
| 第7周 测试验收 | 自动测试、固定模拟集、操作步骤 | 专业摘要可用性评分、可用性访谈、真实接管测试 |
| 第8周 试点演示 | 可复现版本、演示脚本和证据目录 | 授权试点、实际录像、成本票据与效果对照 |

## 指标的统计边界

字段抽取和路由目标 ≥90%（至少100条人工标注记录），来源可定位率100%，成功越权调用0，人工接管目标≥95%（指定环境至少50次），摘要可用性≥80%，登记效率降低20%仅为探索目标。合成数据上的程序回归不能证明真实人群效果，接口进入人工队列不能证明工作人员真实接通。不得以代码已实现取代这些实证条件。

## 交付与版本纪律

阶段结束时运行相关检查，更新 README、PROGRESS 及测试记录，然后单独提交并推送。未能运行的检查明确记录；不将真实身份、案卷、密钥、数据库或原始录音上传仓库。
